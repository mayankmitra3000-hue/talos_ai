About AIRes Pro

AIRes Pro is an intelligent resume analysis platform designed to help students and professionals improve their resumes using Artificial Intelligence. Our goal is to simplify resume evaluation and provide meaningful insights that help users prepare for internships and job opportunities.

🚀 Features

  • ✔ Upload and securely store resumes.
  • ✔ AI-powered resume analysis.
  • ✔ Resume history management.
  • ✔ View resumes anytime.
  • ✔ Fast and responsive user interface.

💻 Technologies Used

  • • Java & Spring Boot
  • • Spring MVC
  • • Spring Data JPA
  • • MySQL Database
  • • Thymeleaf
  • • Tailwind CSS
  • • Apache PDFBox
  • • Groq AI API

🎯 Our Mission

We aim to bridge the gap between job seekers and recruiters by leveraging Artificial Intelligence to provide instant resume feedback. Our mission is to make resume improvement simple, accessible, and effective for everyone.
